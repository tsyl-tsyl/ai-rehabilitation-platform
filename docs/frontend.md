# 前端功能说明

## 主要页面结构
- index.html：主入口页面
- aphasia/、lower_limb/、upper_limb/：各康复场景页面
- js/：核心脚本（如 common.js、平台交互、AI推理等）
- css/：样式文件
- locales/：多语言 json 文件

## 主要功能
- 智能训练计划入口与展示
- 姿态识别与实时反馈
- 训练统计与历史图表
- 成就系统与个性化设置
- 多语言切换与UI适配

## 交互说明
- 与后端API通过 fetch/axios 进行数据交互
- 机器人/硬件接口可通过 websocket、串口等方式集成

## 资源管理
- 图片、第三方库建议通过 CDN 或 .gitignore 管理
- 仅保留必要的演示资源，避免上传大文件
